Pretrained BPR and TextBPR compact CPU bundles from the earlier Kaggle 70/15/15 experiment.

Accepted for the current application delivery under Contracts v1.1. Original
weights, mappings, checksums and experiment provenance are preserved.

No retraining, GPU or text-encoder download is needed for catalog recommendations.
Install using scripts/install_model.py and the manifest on the models branch;
see docs/PRETRAINED_MODELS.md. Keep model_info.json with weights.npz.

Includes source user/game mappings and observed training history. Intended for
collaborators of this private repository. Source display names are not verified
application account identities; new accounts should use explicit popularity fallback.

These are legacy experiment artifacts, not models trained under Contracts v1.
The release does not contain a complete UI/backend application. Do not relabel
fingerprints or use these artifacts to claim v1 benchmark results.
